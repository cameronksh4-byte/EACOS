# App won't install / update; licence won't activate

Area: Software / Apps. Handling: Escalate-only. Give only the safe first steps below, collect the handoff packet (KB-POLICY-HANDOFF), and hand off to a person. Don't troubleshoot further.

**What users say:** “It won't install” · “It says I'm not licensed”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Safe first steps:**
1. Check free disk space and whether an older version is still there.
2. Read the actual error code.
3. Check which account the app is signed into — users often have two — and whether a licence is assigned in the admin portal.

**If that doesn't fix it:** Diagnose only. Install from the company portal (not a download); sign out and back in with the licensed account; for a failed update, uninstall then install the current version fresh — all human/admin steps.

**Escalate to a person when:** The package fails on more than one machine, a licence / seat problem, activation fails across the organisation after a renewal, or any install needing local admin — human / admin (and purchasing, if it's a licence issue).

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
