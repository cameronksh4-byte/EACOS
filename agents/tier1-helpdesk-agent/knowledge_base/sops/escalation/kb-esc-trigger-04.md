# Must escalate: Hardware failure

Handling: Escalate-only. The agent does not attempt a fix. It gives only the safe first aid below, collects the handoff packet (KB-POLICY-HANDOFF), and hands off immediately to the client's named human contact, with urgency.

**Triggers:** PC won't turn on, repeated blue screens, clicking or grinding, burning smell or heat, drive SMART errors, ports failing across a batch, monitor / dock failure across the fleet.

**Collect for the handoff:** Device make / model / asset tag, symptoms and when they started, any recent drop, spill, or update, whether data on it is backed up, whether a loan machine is needed.

**Safe first aid only:** Unplug if there's a smell, smoke, or heat. Otherwise stop retrying and stop using it. A human diagnoses, arranges a loan machine, and backs up before any disk work.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
