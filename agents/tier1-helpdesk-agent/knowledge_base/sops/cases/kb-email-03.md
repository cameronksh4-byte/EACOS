# Calendar not syncing / wrong time

Area: Email / Outlook. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “The meeting is on my laptop but not my phone” · “All my meetings moved an hour”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Compare against Outlook on the web — the server copy decides which device is wrong.
2. Check time zone / automatic time zone on each device.
3. Check whether the account is added twice on the phone.

**If that doesn't fix it:** Remove and re-add the account on the out-of-date device; check delegate permissions and duplicate calendar apps.

**Escalate to a person when:** The whole team, or a room / resource calendar, is out of step — admin / room-mailbox work.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
