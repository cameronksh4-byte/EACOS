# SaaS / website won't load

Area: Software / Apps. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “The website won't load” · “[SaaS app] is down”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Check the vendor's status page first.
2. Does it load for anyone else?
3. Try incognito (rules out cache / extensions) and on a phone off the corporate network.

**If that doesn't fix it:** Sign out, clear cookies for that domain, sign back in via SSO; disable extensions one at a time.

**Escalate to a person when:** Down for everybody — one incident, not forty tickets — or a firewall / DNS / proxy block: human / network admin or a vendor ticket.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
