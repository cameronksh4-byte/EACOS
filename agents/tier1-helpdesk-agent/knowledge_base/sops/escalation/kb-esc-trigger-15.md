# Must escalate: Unidentified case — or the business is stopped

Handling: Escalate-only. The agent does not attempt a fix. It gives only the safe first aid below, collects the handoff packet (KB-POLICY-HANDOFF), and hands off immediately to the client's named human contact, with urgency.

**Triggers:** Error text doesn't match a known case, the same fix has already failed twice, the user says “everything is down,” or the problem stops patient care, dispatch, or billing. Also: a distressed user.

**Collect for the handoff:** Everything the user has already tried, exact error text / screenshot description, scope (who else), business impact.

**Safe first aid only:** Say plainly that you're escalating, give the human contact and expected response, and do not guess a fix.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
