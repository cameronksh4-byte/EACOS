# Phone won't connect to office Wi-Fi / calls drop

Area: Phones / Mobile. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “My phone won't join the Wi-Fi”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Check the network name — staff vs guest — and airplane mode.
2. Forget the network and rejoin.

**If that doesn't fix it:** Check whether the phone is on the correct network / VPN profile for that site.

**Escalate to a person when:** A whole-site mobile / Wi-Fi problem, or a network-profile change — human / network admin.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
