# Email / apps on phone not working

Area: Phones / Mobile. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “Outlook on my phone won't sync” · “The app keeps crashing”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Check Wi-Fi vs mobile data — does it work on data?
2. Restart the phone.
3. Check the account isn't added twice; check app and OS updates.

**If that doesn't fix it:** Remove and re-add the account on the phone; reinstall the app — push tokens get stuck.

**Escalate to a person when:** A lost or stolen phone, or any remote wipe, device enrolment, or MFA re-enrolment — human, with identity proof and the MDM action.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
