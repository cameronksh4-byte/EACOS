# Must escalate: Compliance / PHI issues (clinics)

Handling: Escalate-only. The agent does not attempt a fix. It gives only the safe first aid below, collects the handoff packet (KB-POLICY-HANDOFF), and hands off immediately to the client's named human contact, with urgency.

**Triggers:** Any case involving patient data (PHI / ePHI), the EHR, a misdirected email or message containing PHI, a lost device with patient data, a suspected breach of patient data, or any request to access, export, or share patient records.

**Collect for the handoff:** What system / data is involved, when it happened, who was affected (a count, not names in chat unless the human's secure channel requires it), whether the data left the clinic's systems — and NO PHI itself in the chat.

**Safe first aid only:** Do not ask for, paste, or store any PHI in chat. Stop, preserve what happened (times, system), and escalate immediately to the clinic's privacy / compliance contact AND human IT.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
