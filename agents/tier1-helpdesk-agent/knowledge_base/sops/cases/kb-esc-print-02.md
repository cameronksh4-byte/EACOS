# Scanner / scan-to-email or scan-to-folder fails

Area: Printers. Handling: Escalate-only. Give only the safe first steps below, collect the handoff packet (KB-POLICY-HANDOFF), and hand off to a person. Don't troubleshoot further.

**What users say:** “It scans but the email never arrives” · “Scan to folder says error”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Safe first steps:**
1. Check the destination — email address or folder path — is correct.
2. Test a scan to USB or to the printer itself, to separate the scanner from the destination.

**If that doesn't fix it:** Scan-to-email fails at SMTP settings; scan-to-folder fails at share permissions. Both are admin-side — diagnose only.

**Escalate to a person when:** Any SMTP, share, or permission change — human admin, always.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
