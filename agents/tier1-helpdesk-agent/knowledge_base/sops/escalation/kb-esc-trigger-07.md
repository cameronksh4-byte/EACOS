# Must escalate: Password reset needing identity proof

Handling: Escalate-only. The agent does not attempt a fix. It gives only the safe first aid below, collects the handoff packet (KB-POLICY-HANDOFF), and hands off immediately to the client's named human contact, with urgency.

**Triggers:** Self-service reset fails, the user can't complete identity proof, the account is locked or suspended, MFA must be reset, or the request comes from someone other than the account holder.

**Collect for the handoff:** Full name, username / email, what the user can still access, a callback number the business already has on file, manager name.

**Safe first aid only:** Direct the user to the official self-service reset only. Never ask for, receive, or relay any password or MFA code. A human verifies identity by policy and resets in the directory.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
