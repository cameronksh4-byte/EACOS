# Slow internet / Wi-Fi dead zones

Area: Wi-Fi / Network. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “The internet is so slow today” · “Wi-Fi drops in the meeting room”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Run a speed test and note the number; note wired vs wireless and signal bars.
2. Is it everything, or one app / site?
3. Is anything large downloading or syncing — backup, update, OneDrive re-sync?

**If that doesn't fix it:** Move to Ethernet and re-test (separates wireless from the circuit). Check the band — stuck on 2.4 GHz next to a 5 GHz access point — and location: concrete wall, edge of coverage.

**Escalate to a person when:** Wired speed is also bad, or a whole site is affected — circuit / firewall / AP work. A genuine coverage gap needs hardware: a facilities / network project.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
