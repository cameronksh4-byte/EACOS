# Keyboard / mouse / USB not working

Area: Monitors / Hardware. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “My keyboard stopped working” · “USB device not recognized”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Try a different port — on the machine, not a hub or dock. Check batteries, power switch, and dongle on wireless devices.
2. Test the device on another machine — that settles device vs machine.

**If that doesn't fix it:** A human checks Device Manager (yellow warning → uninstall device, scan for hardware changes), turns off USB selective suspend, and updates chipset / USB drivers from the laptop vendor.

**Escalate to a person when:** Ports failing across a batch of the same model, or a replacement is needed — human (spare swap / warranty / ordering).

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
