# Must escalate: Security incident (general)

Handling: Escalate-only. The agent does not attempt a fix. It gives only the safe first aid below, collects the handoff packet (KB-POLICY-HANDOFF), and hands off immediately to the client's named human contact, with urgency.

**Triggers:** Phishing clicked with credentials / MFA given, suspected breach, unauthorised access, data sent to the wrong person, a lost or stolen laptop or phone with company data, multiple accounts locking at once.

**Collect for the handoff:** What happened, in order, with times; what was clicked / opened / entered / approved / sent; who else is affected; the device involved.

**Safe first aid only:** Contain only as in the relevant row — disconnect, stop using the account or device, don't delete the message or evidence. Human / security owns containment, investigation, and notification.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
