# Must escalate: Remote access on the user's behalf

Handling: Escalate-only. The agent does not attempt a fix. It gives only the safe first aid below, collects the handoff packet (KB-POLICY-HANDOFF), and hands off immediately to the client's named human contact, with urgency.

**Triggers:** Any request for the agent or IT to “take over my screen,” install software remotely, or change settings on the user's machine.

**Collect for the handoff:** User, device, what needs doing, whether the user is present and consents, best contact method and time.

**Safe first aid only:** The AI never starts remote access on its own. A human may do so only through the business's approved remote tool, with the user present and consenting.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
