# Must escalate: Admin / permission changes

Handling: Escalate-only. The agent does not attempt a fix. It gives only the safe first aid below, collects the handoff packet (KB-POLICY-HANDOFF), and hands off immediately to the client's named human contact, with urgency.

**Triggers:** Any request to grant, change, or remove access to a folder, mailbox, app, or system; licence / seat changes; group-membership changes.

**Collect for the handoff:** Who needs access, to what exactly (read vs edit), why, manager / data-owner approval, start and end date if temporary.

**Safe first aid only:** None — the agent records the request and routes it for approval. It never grants, changes, or removes access itself.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
