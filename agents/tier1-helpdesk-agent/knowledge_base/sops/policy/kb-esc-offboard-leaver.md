# Leaver (offboarding) request

Handling: Escalate-only. This is a request, not a fix, and it is acted on the same day. The agent never disables accounts, removes access, or transfers data itself.

**Collect:**
1. Name, last day and time, and manager
2. Equipment to return
3. Email and file ownership to transfer, and who takes over shared mailboxes and files

**A person then:** disables the account the same day, revokes sessions, removes VPN and app access and MFA tokens, transfers ownership, recovers the licence, and checks that access is gone. A leaver's account is never left active "just in case", and their password or login is never reused or shared with a replacement.
