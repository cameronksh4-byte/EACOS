# Request access to Figma

## When to use
You need a Figma seat. Figma requires your manager's approval because each seat is licensed.

## Steps for the user
1. Ask for Figma in the help desk chat and say what you'll use it for.
2. Your manager receives an approval request.
3. Once approved, sign in at figma.com with **Log in with SAML SSO** using your work email.

## Escalate to Tier 2 when
- You were approved but still can't sign in after an hour.
