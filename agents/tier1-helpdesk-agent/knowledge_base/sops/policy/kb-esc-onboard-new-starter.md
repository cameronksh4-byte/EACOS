# New starter (onboarding) request

Handling: Escalate-only. This is a request, not a fix. The agent never creates accounts, assigns licences, sets passwords, or grants access. It collects a complete request and hands it to the person who owns IT. If the manager, role, or access list is missing, ask and wait; never guess access.

**Collect before day one:**
1. Full name (and preferred display name), start date, manager, role or department
2. Work location (office, home, or both) and employee or contractor status
3. Systems the role needs: email, apps, shared drives, printers, phone extension, VPN
4. Equipment: laptop or desktop, monitor, dock, headset
5. The manager's approval for access, with a "same access as [named colleague in the same role]" reference. Never "give them everything".

**A person then:** creates a named account (never a shared login), assigns the licence, enrols MFA with the user, adds role groups and drives, sets up the phone extension, and gives a one-page welcome sheet. No password is ever written down.
