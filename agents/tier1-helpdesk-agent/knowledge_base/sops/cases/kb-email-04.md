# Teams / video-call problems

Area: Email / Outlook. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “Nobody can hear me” · “My camera doesn't work” · “The call keeps freezing”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Check the device selected inside Teams / Zoom / Meet audio-video settings — not Windows settings.
2. Close other meeting apps — only one app can hold the camera.
3. Check the OS privacy permission for camera and microphone.
4. Use a headset for echo; run the app's test call.

**If that doesn't fix it:** Move to Ethernet; check whether VPN routing is hurting call quality; update or reinstall the meeting client.

**Escalate to a person when:** Poor quality across a team or office — that's network capacity, not a client problem.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
