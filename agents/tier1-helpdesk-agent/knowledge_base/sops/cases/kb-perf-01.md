# Slow / laggy PC

Area: Slow Computers. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “My computer is so slow” · “Everything takes forever”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Restart properly — Shut down, then Start. Closing the lid isn't a restart; Fast Startup keeps the old session.
2. Open Task Manager / Activity Monitor; sort by memory, then CPU. Note how long since the last restart, and whether it's slow everywhere or in one app.
3. Close excess browser tabs; check free space on the system drive — under 10% free slows everything.

**If that doesn't fix it:** Trim startup items (Task Manager → Startup); clear temp files; check for a sync client, antivirus scan, or Windows update running during the day.

**Escalate to a person when:** SMART warnings or drive errors, repeated slowness after the above, or the fix is a hardware upgrade (RAM / disk) — human, with a backup taken before any disk work.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
