# Mailbox full

Area: Email / Outlook. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “Outlook says my mailbox is full” · “I can't send, it says quota”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Empty Deleted Items and Junk.
2. Sort by size; delete or detach the largest attachments.
3. Check OneDrive / cloud storage too — full cloud storage also blocks mail (Microsoft Support).

**If that doesn't fix it:** Still full after emptying? The hidden Recoverable Items folder may be holding mail — an archive or quota increase is needed.

**Escalate to a person when:** A quota can't be raised without a licence change, or it's a shared mailbox — human / admin decision, with the mailbox owner's agreement before any clean-up.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
