# App won't open / crashes

Area: Software / Apps. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “Word / QuickBooks / [app] keeps crashing” · “It won't open”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Get the exact error text or a screenshot — “it crashed” and “file is in use” are different tickets.
2. Does it crash on open, or at one action? One user, or several? Was the app or OS updated in the last few days?
3. Try the same file / action on another machine.

**If that doesn't fix it:** Start the app with add-ins disabled (Office: hold Ctrl while launching). Repair the installation before reinstalling. Rename the app's local cache / profile folder so it rebuilds.

**Escalate to a person when:** The same crash hits multiple users (bad release, or a service the app depends on), or the fix needs an install / reinstall with admin rights — human / vendor.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
