# GlobalProtect VPN will not connect

## Steps for the user
1. Check that you have internet access by opening any public website.
2. Click the GlobalProtect icon in the system tray, then **Disconnect**, then **Connect**.
3. If you see "portal not found", confirm the portal address is `vpn.example.com`.
4. Restart your computer, then try to connect again.
5. If it still fails, reply with a screenshot of the error message.

## Escalate to Tier 2 when
- More than one user reports the same error at the same time (possible outage, treat as P1).
- The error mentions a certificate.
