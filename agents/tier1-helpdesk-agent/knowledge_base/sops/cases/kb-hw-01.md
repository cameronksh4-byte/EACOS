# Second monitor not detected / no display

Area: Monitors / Hardware. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “My second screen is black” · “The monitor isn't detected”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Check the monitor is on and on the right input; check the cable is seated.
2. Press Win+P (Windows) or check display settings (macOS) — is it detected but not extended?
3. Plug the monitor straight into the laptop, bypassing the dock.

**If that doesn't fix it:** Power-cycle the dock properly — unplug from the mains for 30 seconds. Swap the cable before swapping the dock; cables fail more often. Detect displays manually and check the resolution / refresh the cable can carry.

**Escalate to a person when:** The same dock model fails across the fleet, or any firmware / graphics-driver change — human / vendor.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
