# Browser problems

Area: Software / Apps. Handling: Guide the user through the steps, then escalate if the escalation point is reached.

**What users say:** “The page won't load / looks broken”

**Ask first:** One user, or everyone? When did it start, and what changed?

**Steps for the user, in order:**
1. Same page in incognito; another browser; same page on a phone off the network.
2. Note the exact ERR_ code.

**If that doesn't fix it:** Clear cache and cookies for that one site only; disable extensions one at a time; update the browser and close every window.

**Escalate to a person when:** A certificate or proxy problem hitting everyone — network / security team.

Shared baseline knowledge base: generic steps. A client's own SOP for the same issue wins. Never collect a password or MFA code; never make admin or permission changes.
